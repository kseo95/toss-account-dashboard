# 토스증권 포트폴리오 대시보드 (redo)

토스증권 Open API 연동을 처음부터 다시 만드는 작업 폴더입니다. 현재는 로그인 화면에서 앱키/시크릿을 입력해 계좌 목록을 조회하는 단계까지 구현되어 있습니다.

> **조회 전용입니다.** 코드에서 호출하는 POST는 로그인 시 토큰 발급 하나뿐이며, 주문은 나가지 않습니다.

## 앱키/시크릿(client_id / client_secret) 발급받기

1. **토스증권 WTS(웹 트레이딩 시스템)** 에 로그인합니다.
2. **설정 > Open API** 메뉴로 들어가 `client_id`와 `client_secret`을 발급받습니다. (로그인 후 화면 **우측 하단의 톱니바퀴 아이콘**이 설정 버튼입니다.)
3. **같은 화면 하단의 "허용 IP 관리"에 API를 호출할 IP를 반드시 등록**하세요. 등록되지 않은 IP에서의 호출은 403으로 차단됩니다.
   - 이 대시보드는 내 컴퓨터(localhost)에서 실행되지만, 토스 API로 나가는 요청은 **내 컴퓨터의 공인(외부) IP**를 통해 나갑니다. 아래 명령으로 확인해서 등록하세요.
     ```bash
     curl -s ifconfig.me
     ```
   - 가정용 인터넷처럼 **IP가 유동적으로 바뀌는 환경**이면, IP가 바뀔 때마다 로그인이 다시 403으로 막힐 수 있습니다 — 이 경우 위 명령으로 현재 IP를 다시 확인해 허용 목록을 갱신하세요.
4. 발급받은 `client_id`(앱키)와 `client_secret`(시크릿)을 아래 실행 후 뜨는 로그인 화면에 그대로 입력하면 됩니다. **`.env` 파일이 따로 필요 없습니다** — 이 폴더는 화면에서 직접 입력받는 "로그인 방식"으로 만들었습니다.

참고: 클라이언트(앱키)당 유효한 토큰은 동시에 1개뿐이라, 같은 앱키로 다른 곳(예: `../real/`)에서 동시에 토큰을 발급받으면 서로의 토큰이 무효화될 수 있습니다.

## 설치

Python 3.9 이상이 필요하고, 외부 패키지는 `requests` 하나뿐입니다.

```bash
pip3 install requests
```

## 실행

```bash
cd /Users/john/Desktop/Portfolio/toss-portfolio/redo
python3 server.py
```

브라우저에서 http://127.0.0.1:8767 을 엽니다. 서버는 localhost 전용이라 외부에서 접속할 수 없습니다.

로그인 화면에서 앱키/시크릿을 입력하면 토큰을 발급받고, 조회된 계좌 목록을 보여줍니다. 앱키/시크릿/토큰은 **디스크에 저장하지 않고 서버 프로세스 메모리에만** 세션 단위로 보관하므로, 서버를 재시작하면 다시 로그인해야 합니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `dashboard.html` | 웹 화면 (로그인 카드 + 연결 후 계좌 목록) |
| `server.py` | 웹 서버. 로그인(`/api/login`), 세션 확인(`/api/session`), 계좌 조회(`/api/accounts`), 로그아웃(`/api/logout`) |
| `CLAUDE.md` | AI 어시스턴트(Claude Code)에게 주는 프로젝트 지침 |
| `CHANGELOG.md` | 작업 로그 |
| `docs/` | 구조/전략 문서 |

## 주의사항

- 앱키/시크릿은 내 토스증권 계좌에 접근할 수 있는 민감 정보입니다. 로그인 화면 외의 곳(채팅, 커밋 등)에 남기지 마세요.
- 아직 보유 종목·평가금액·리밸런싱 등은 구현되지 않았습니다(계좌 목록 조회까지만). 자세한 진행 상황은 `CHANGELOG.md`를 참고하세요.
- 이 프로젝트는 개인 학습용이며 투자 조언이 아닙니다.
