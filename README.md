# 토스증권 포트폴리오 대시보드 (redo)

토스증권 계좌의 보유종목·예수금 현황을 한눈에 보여주는 개인용 대시보드입니다. 앱키/시크릿만 입력하면 바로 시작할 수 있습니다.

> **조회 전용입니다.** 이 앱은 계좌 정보를 읽어오기만 하고, 매수·매도 주문은 절대 넣지 않습니다.

## 주요 기능

- 로그인 후 국내/해외 보유종목, 수량, 평가금액, 손익, 수익률 확인
- 예수금(원화/달러) 및 현금처럼 다루고 싶은 종목을 한곳에 모아 보기
- USD/KRW, USD/JPY 환율 표시
- 보유 비중을 도넛 그래프로 확인
- 원하는 종목/그룹별로 목표 비중을 직접 정하고 화면에서 언제든 수정
- 원화/달러 목표 비중 설정
- 관심종목: 종목명/티커로 검색해서 추가, 현재가·등락률 확인
- MA(이동평균) 감시: 원하는 종목에 일봉/주봉·기간·근접 기준%를 직접 정해서 등록
- 분할매수 전략(1차 사이클): 여러 이동평균을 단계별로 하방 돌파할 때마다 매수 비율을 누적하고, 이후 반등하면 나머지 비율을 채워 진입을 완성 — 단계/비율 전부 화면에서 설정 가능

## 앱키·시크릿 발급받기

1. 토스증권 웹사이트에 로그인합니다.
2. **설정 > Open API** 메뉴로 들어가 앱키(client_id)와 시크릿(client_secret)을 발급받습니다. (로그인 후 화면 **우측 하단의 톱니바퀴 아이콘**이 설정 버튼입니다.)
3. 같은 화면 하단의 **"허용 IP 관리"에 내 컴퓨터의 IP를 등록**하세요. 등록하지 않으면 로그인이 안 됩니다. 아래 명령으로 내 IP를 확인할 수 있습니다.
   ```bash
   curl -s ifconfig.me
   ```
   집에서 쓰는 인터넷처럼 IP가 종종 바뀌는 환경이면, 로그인이 갑자기 안 될 때 이 명령으로 IP를 다시 확인해서 갱신해주세요.
4. 발급받은 앱키와 시크릿을 대시보드 로그인 화면에 그대로 입력하면 됩니다.

## 설치 및 실행

```bash
git clone https://github.com/kseo95/toss-account-dashboard.git
cd toss-account-dashboard
pip3 install requests
python3 server.py
```

브라우저에서 http://127.0.0.1:8767 을 엽니다. 로그인 화면에서 앱키/시크릿을 입력하면 바로 내 계좌 현황이 뜹니다.

앱키/시크릿은 저장되지 않고, 서버를 껐다 켜면 다시 입력해야 합니다.

## 주의사항

- 앱키/시크릿은 내 토스증권 계좌에 접근할 수 있는 민감 정보입니다. 남에게 공유하지 마세요.
- 수수료 반영 방식 차이로 인해 손익/수익률 수치가 토스 앱 화면과 조금 다를 수 있습니다.
- 해외 주식의 경우 환율 변동 효과까지 정확히 반영한 손익은 아닙니다.
- 이 프로젝트는 개인 학습용이며 투자 조언이 아닙니다.
