# 토스증권 포트폴리오 대시보드 (redo)

토스증권 Open API 연동을 처음부터 다시 만드는 작업 폴더입니다. **앱키/시크릿만 입력하면** 예수금(원화/달러), 국내 종목, 해외 종목 현황과 총 평가금액/손익/수익률을 보여줍니다.

> **조회 전용입니다.** 코드에서 호출하는 POST는 로그인 시 토큰 발급, 현금 취급 종목 설정 저장뿐이며, 주문은 나가지 않습니다.

## 주요 기능

- **로그인**: `.env` 없이 화면에서 앱키/시크릿을 입력하면 그 자리에서 토큰 발급 (세션은 서버 메모리에만 유지, 디스크 저장 없음)
- **보유종목 표**: 국내/해외 구분, 수량, 평가금액, 손익, 수익률, 지분율 (지분율·수익률 분모는 예수금 포함 총자산 기준)
- **해외 종목 원/$ 토글**: 평가금액·손익을 원화 또는 달러로 전환해서 보기
- **현금 표**: 원화/달러 예수금 + "현금 취급 종목"으로 지정한 종목(SGOV 등)을 한 데 모아 보여줌
- **현금 취급 종목 설정**: 보유종목 중에서 체크박스로 선택. 설정은 보유 여부와 무관하게 저장되므로, 전량 매도해도 사라지지 않고 나중에 다시 사면 자동으로 다시 현금 취급됨
- **상단 요약**: 총 평가금액(예수금 포함) / 총 손익 / 총 수익률
- **보유 비중 도넛차트**: 리밸런싱 목표 카테고리별 현재%/목표% (범례에 "현재% / 목표%" 표기, 아직 안 산 목표 카테고리는 도넛엔 안 나오고 범례에만 회색으로 남음)
- **원/달러 비율 도넛차트**: 전체 자산(예수금 포함) 중 원화/달러 비중
- **리밸런싱 목표 설정 (화면에서 편집)**: 종목을 카테고리로 묶어서 목표 비중을 정함. 종목 하나만 넣으면 개별 설정, 여러 개 넣으면(예: KODEX 200 + KODEX 인버스) 합쳐서 하나의 목표%. 카테고리로 안 묶인 종목/예수금은 하나로 안 뭉치고 각각 개별 항목으로 표시되며, 목표%는 "미분류 종목 기본 목표%"(기본 5%, 이것도 화면에서 편집 가능)로 고정됨. 저장 시 종목 코드가 실제로 존재하는지 토스 API로 확인.

## 리밸런싱 목표 설정

**"보유 비중" 카드 안의 "리밸런싱 목표 설정"을 펼쳐서 화면에서 직접 편집**합니다 (`.env`처럼 파일을 직접 건드릴 필요 없음). 카테고리 추가 → 이름/종목 코드(쉼표로 구분)/목표% 입력 → 저장.

내부적으로는 `rebalance.json`에 이렇게 저장됩니다 (직접 열어볼 수는 있지만, 편집은 화면에서 하는 걸 권장합니다):

```json
{
  "targets": [
    { "label": "미국 대형주", "symbols": ["AAPL", "MSFT"], "target_pct": 30 },
    { "label": "코스피200 시소", "symbols": ["069500", "114800"], "target_pct": 10 }
  ],
  "default_rest_target_pct": 5
}
```

- `targets`: 카테고리 배열. `symbols`에 묶인 종목들의 평가금액 합이 그 카테고리의 "현재%"가 됩니다.
- `default_rest_target_pct`: 어느 카테고리에도 속하지 않은 종목/예수금 각각에 적용되는 기본 목표%.
- 파일이 없으면 카테고리 없이 시작합니다(모든 보유종목이 미분류로 각각 5%).
- 같은 종목을 두 카테고리에 넣는 건 금액 이중 집계라 저장이 거부됩니다. 카테고리 이름 중복·예약어("나머지"/"현금")도 거부됩니다.
- 목표% 합계가 100%가 아니어도 저장은 되지만(경고만), 화면 숫자가 이상해 보일 수 있으니 맞춰두는 걸 권장합니다.

## 앱키/시크릿(client_id / client_secret) 발급받기

1. **토스증권 WTS(웹 트레이딩 시스템)** 에 로그인합니다.
2. **설정 > Open API** 메뉴로 들어가 `client_id`와 `client_secret`을 발급받습니다. (로그인 후 화면 **우측 하단의 톱니바퀴 아이콘**이 설정 버튼입니다.)
3. **같은 화면 하단의 "허용 IP 관리"에 API를 호출할 IP를 반드시 등록**하세요. 등록되지 않은 IP에서의 호출은 403으로 차단됩니다.
   - 이 대시보드는 내 컴퓨터(localhost)에서 실행되지만, 토스 API로 나가는 요청은 **내 컴퓨터의 공인(외부) IP**를 통해 나갑니다. 아래 명령으로 확인해서 등록하세요.
     ```bash
     curl -s ifconfig.me
     ```
   - 가정용 인터넷처럼 **IP가 유동적으로 바뀌는 환경**이면, IP가 바뀔 때마다 로그인이 다시 403으로 막힐 수 있습니다 — 이 경우 위 명령으로 현재 IP를 다시 확인해 허용 목록을 갱신하세요.
4. 발급받은 `client_id`(앱키)와 `client_secret`(시크릿)을 아래 실행 후 뜨는 로그인 화면에 그대로 입력하면 됩니다. **`.env` 파일이 따로 필요 없습니다** — 이 폴더는 화면에서 직접 입력받는 "로그인 방식"으로 만들었습니다.

참고: 클라이언트(앱키)당 유효한 토큰은 동시에 1개뿐이라, 같은 앱키로 다른 곳(예: `../real/`)에서 동시에 토큰을 발급받으면 서로의 토큰이 무효화될 수 있습니다.

## 설치

Python 3.9 이상이 필요하고, 외부 패키지는 `requests` 하나뿐입니다.

```bash
pip3 install requests
```

## 실행

```bash
cd /Users/john/Desktop/Portfolio/toss-portfolio/redo
python3 server.py
```

브라우저에서 http://127.0.0.1:8767 을 엽니다. 서버는 localhost 전용이라 외부에서 접속할 수 없습니다.

로그인 화면에서 앱키/시크릿을 입력하면 토큰을 발급받고, 보유종목·예수금 현황을 보여줍니다. 앱키/시크릿/토큰은 **디스크에 저장하지 않고 서버 프로세스 메모리에만** 세션 단위로 보관하므로, 서버를 재시작하면 다시 로그인해야 합니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `dashboard.html` | 웹 화면 (로그인 카드 + 보유종목/예수금 현황) |
| `server.py` | 웹 서버. 로그인(`/api/login`), 세션 확인(`/api/session`), 계좌 조회(`/api/accounts`), 보유종목 조회(`/api/holdings`), 현금 취급 종목 설정(`/api/cash-symbols`), 리밸런싱 목표 설정(`/api/rebalance-config`), 로그아웃(`/api/logout`) |
| `cash_symbols.json` | 현금 취급 종목 설정 (자동 생성, 개인 데이터라 `.gitignore` 처리됨) |
| `rebalance.json` | 리밸런싱 목표 설정 (화면에서 저장하면 자동 생성, 개인 데이터라 `.gitignore` 처리됨) |
| `CLAUDE.md` | AI 어시스턴트(Claude Code)에게 주는 프로젝트 지침 |
| `CHANGELOG.md` | 작업 로그 |
| `docs/` | 구조/전략 문서 |

## 주의사항

- 앱키/시크릿은 내 토스증권 계좌에 접근할 수 있는 민감 정보입니다. 로그인 화면 외의 곳(채팅, 커밋 등)에 남기지 마세요.
- 손익/수익률은 토스 API의 수수료·세금 반영 후 값(`amountAfterCost`/`rateAfterCost`)을 사용합니다. 토스 앱 화면(반영 전 기준으로 추정)과 최대 몇 달러/1%p 수준의 작은 차이가 날 수 있습니다(의도된 것입니다).
- 매입 시점 환율을 반영한 환차손익은 계산하지 않습니다(토스 API가 매입 시점 환율 정보를 제공하지 않음).
- 주봉 이동평균선(MA), 관심종목, 분할매수 전략은 아직 없습니다. 자세한 진행 상황은 `CHANGELOG.md`를 참고하세요.
- 이 프로젝트는 개인 학습용이며 투자 조언이 아닙니다.
